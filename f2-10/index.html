1. 株価の水準の意味

A社の株価が3,000円で、B社が500円だとします。この2つを比べても、何も言えません。株価は、会社を何株に分けているかで変わるからです。同じ会社でも、株式数を2倍にすれば、1株の値段はおおよそ半分になります。株価の水準は、会社の規模とも、割高か割安かとも関係がありません。

比べる相手は、その1株が生み出している利益、つまり F2-09 の EPS です。

2. PER の計算と単位

株価を EPS で割った倍率を PER と呼びます。F2-09 の架空の会社では、株価1,500円を EPS 100円で割って15倍です。数値はすべて説明のために作ったものです。

この15倍の意味は、単位を見ると分かります。株価は円で、EPS は1年あたりの円なので、割ると単位は年になります。いまの利益が続くとしたら、払った金額を利益で回収するのに何年かかるかを示すのが PER で、15倍なら利益の15年分を払っていることになります。

3. 株価の直接比較が意味を持たない理由

1節の2社に、EPS を足して比べます。A社は株価3,000円で EPS が300円なので、PER は10倍です。B社は株価500円で EPS が20円なので、PER は25倍です。株価は A社の方が6倍高いのに、PER は A社の方が小さくなっています。株価が高いか安いかと、PER が高いか低いかは、別の話です。

E1-13 では、1ドルが150円と数字が大きくなっても円安だと見ました。F2-09 では、比の変化を分子と分母に分けて読みました。数字を、何で割った値なのかまで含めて見るという点で、どれも同じです。

4. 将来期待の裏返し

F2-02 で、将来受け取るお金を今に直して足したものが、理屈の上での価格になると見ました。この見方から PER を読むと、意味が変わります。株価は将来の利益を今に直したもので、EPS はいまの1年分の利益です。PER は、いまの利益に対して、将来の見込みがどれだけ乗っているかを映します。

EPS が同じ2社で PER が違うなら、市場は違うことを見込んでいます。PER が大きければ、将来の利益がいまより増えると見込まれている、という読み方が1つできます。ただし、それだけではありません。F2-02 で、割引率には返ってこないおそれ（信用リスク）が入ると見ました。将来の見込みが同じでも、確からしさが低いと見られれば割引率は大きくなり、価格は小さくなります。PER が小さいことは、将来があまり期待されていないとも、不確かさが大きいと見られているとも読めます。

どちらなのかを、このカリキュラムは判定しません。PER は答えではなく、市場は何を見込んでいるのかを問うための入口です。

5. 使うときの注意

PER を使うときは、どの EPS で割ったのかを確かめます。F2-09 では、一時的な要因を含む EPS が100円、除いた EPS が70円でした。株価1,500円で計算すると、前者では15倍、後者では約21.4倍です。同じ会社、同じ株価なのに、15倍とも21.4倍とも書けます。PER を示されたら、どの EPS で割った値なのかを聞きます。

利益がマイナスや0のときは、PER は意味を持ちません。また、業種によって PER の水準には傾向の違いがあり、同じ物差しで並べても前提が違います。その理由の分け方は、L3 の F3-06（セクター分析の手順）で扱います。

6. 逆数で見る

PER をひっくり返して、EPS を株価で割ると、払った金額に対していまの利益がどれだけあるかが分かります。架空の会社では100円÷1,500円で、約6.7%です。PER 15倍は、いまの利益で見ると約6.7%にあたります。この形にすると、F1-08 のリターンや、E1-08 の金利、F2-02 の割引率と並べて眺めることができます。

ただし、この6.7%は約束された利回りではありません。F1-05 の債券と違って、受け取る保証は無く、いまの利益が続くという前提の計算です。F1-01 の地図で言えば、発行体に返す義務があるかどうかの違いで、同じ％の形をしていても、約束のあるものと無いものは別です。この区別を保ったうえでなら、逆数は PER の大きさをつかむ助けになります。

この章は、割安か割高かの判定はせず（F0-01 の線）、どの水準が適正かにも触れません。将来の利益の予想も扱わず、実在の企業の数値も使いません。次の F2-11 では、純資産の側から見た倍率を扱います。
