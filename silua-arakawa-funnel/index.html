2. 道具の説明

6つの道具は、それぞれ何に使い、なぜ要るか

LINE公式アカウント 保有済み

お客様と1対1でつながる"箱"。配信・チャット・リッチメニュー（画面下のボタン）。

単体では全員に同じ文しか送れず、誰がどの投稿から来て何に興味があるか分からない。料金は配信通数で変わる。

Lステップ 推奨

LINE公式を高機能にする外付けツール。ステップ配信・タグ・流入経路分析・診断フォームなど。

無料で始めたいなら「エルメ」。くわしくは次のスライド。

UTAGE（ウタゲ）

販売ページ・決済・メール配信・LINE配信・会員サイト・予約を1つにまとめた道具。

メール配信＝BANの避難所。物販は在庫・発送・送料・返品の管理が要る。注文が増えたらECカート（BASE・STORES・Shopify等）も（案）。

iステップ

インスタで特定の言葉をコメント・DMした人に、自動でDMを返す（似た道具＝エルグラム）。

インスタ→LINEの橋渡し。設定後、別アカウントからコメントしてDMが届くか必ず試す（A社で届かない事例あり）。

オープンチャット 任意

匿名で入れるLINEのグループ。販売前の"盛り上げ"（質問会・ビフォーアフター共有）。

B社では一番売れる場所。ただし12月GOでは必須ではなく、ファンが増えてから追加でよい（案）。

Instagram 配信の主役

リール（新しい人に届く）／ストーリーズ（LINE誘導）／LIVE（実演で一気に売る）／ハイライト（使い方・お客様の声）。

投稿したリールはGoogleドライブ等に保存しておく（BAN対策）。

3. BAN（アカウント停止）の考え方と対策

止まっても売上が止まらない、7つの備え

前提：美容物販は「稼げる系」の商材よりBANリスクは低め。ただしゼロではない。
✓

① 連絡先を2本持つ

LINE登録直後にメールも登録してもらう（UTAGEフォーム・特典と引き換え）

LINEが止まってもメールで全員に連絡できる
✓

② LINEを分ける

入口・配信用（Lステップ）と、購入者・予備用を別アカウントに

1つ止まっても、もう1つは生きる
✓

③ 友だちリストを書き出す

Lステップから毎月CSVで書き出して保存

「誰がお客様だったか」を失わない
✓

④ 送りすぎない・煽りすぎない

配信は週2〜3通が目安。ブロック率・通報が増えたら止める

通報が多いと停止の原因になる
✓

⑤ 規約違反の表現をしない

「絶対」「髪が治る」等の言い切りを避ける（4章）

法律違反は通報・停止の理由になる
✓

⑥ インスタもバックアップ

リール・ストーリーの元データを保存／サブアカウントを用意

集客口が全部消えるのを防ぐ
✓

⑦ 非正規ツールをつながない

正規の連携ツール（Lステップ等）以外でLINEを操作しない

非正規ツールで止まった例が他社で出ている
備えの進み具合

4. 販売する前に必ず確かめる法律・表示（物販特有）

最優先は、アイロンのPSEマークの書面確認

PSEマーク
最優先

ヘアアイロンは電気用品＝PSEマークが無いものは販売できない。仕入れ・OEMなら、メーカー（輸入者）が手続きしているか書面で確認

違反すると販売停止・回収・罰則

特定商取引法の表記

販売者・住所・電話・価格・送料・支払方法・発送時期・返品条件を販売ページに載せる

通販の義務。無いと決済サービスの審査も通らない

返品・交換の条件

「初期不良は交換」「開封後の返品は不可」等を決めて表記

書かないと、届いて8日以内は返品を受けることになる

薬機法・景品表示法

「髪が修復する」「くせ毛が治る」「No.1」等の言い切りを使わない。効果は「個人の感想です」

医薬品・化粧品ではないので"効き目"は言えない

ステマ規制

インフルエンサーに紹介してもらうときは「PR」「広告」を表示してもらう

2023年10月から違反になった

お客様の声の掲載

掲載してよいか・名前の出し方を書面（フォーム）で確認

無断掲載は信頼を失い、トラブルにもなる

v1.0／最終更新：2026-10-25（日）

この資料のゴール：12月に販売を始めた日から「インスタで知る → LINEに入る → 買う → また買う」が人の手をほぼ使わずに回り、LINEが止まっても売上が止まらない状態を作る。

この資料は案です。GO日・使う道具は、ご本人が決めてください。事例は、実際に運用している2つの事業（A社・B社）の形を、名前を伏せて載せています。

  1. 道具の役割分担＝インスタ（集客）→ iステップ（DM自動送信）→ LINE公式＋Lステップ（教育・配信・顧客の振り分け）→ UTAGE（販売ページ・決済・メール・会員ページ＝LINEの外の避難所）

  3. 12月GOに間に合わせるには、11/2（月）の週に「商品・価格・法律表示」、11/9（月）の週に「配信の設計」を決め切ることが分かれ目。構築は11/16（月）〜、テストは11/30（月）の週

2. 道具の説明（何に使うか・なぜ要るか）
2-1. LINE公式アカウント（もう持っている）
  • 何か：LINEの「お店用アカウント」。お客様と1対1でつながる"箱"
  • 何に使うか：配信の送り先・チャット対応・リッチメニュー（画面下のボタン）
  • これだけで足りない理由：全員に同じ文しか送れない。「誰が・どの投稿から来て・何に興味があって・買ったか」が分からない
  • 料金：配信通数で月額が変わる（最新の料金は公式サイトで確認）
2-3. UTAGE（ウタゲ）
  • 何か：販売ページ・決済・メール配信・LINE配信・会員サイト・予約を1つにまとめた道具
  • この動線で何に使うか
用途なぜUTAGEでやるか
販売ページ（LP）作る・直すが自社でできる（B社の事例では運営側がUTAGEで販売ページを作っている）
決済（カード・分割）申込から決済まで同じ画面で完結。購入した人に自動で印（ラベル）が付く
メール配信＝BANの避難所LINEが止まっても、メールで同じお客様に連絡できる。LINE登録直後にメールも取っておくのがBAN対策の要
会員ページ購入者だけが見られる「使い方動画・お手入れ方法」の置き場所
2つ目のLINE（必要になったら）購入者専用LINEをUTAGEで運用する形もできる（A社の事例がこの形）
  • 物販で気をつけること：ブラシ・アイロンは"モノ"なので、在庫・発送・送料・返品の管理が要る。月の注文が少ないうちはUTAGE決済＋手作業の発送でよいが、商品数・注文数が増えたらECカート（BASE・STORES・Shopify 等）を販売ページの行き先にする方が楽（案）
2-4. iステップ（インスタのDM自動化）
  • 何か：インスタで「特定の言葉をコメント・DM」した人に、自動でDMを返す道具（似た道具＝エルグラム）
  • 何に使うか：リールに「ブラシ」とコメント → 自動DMで「LINEで〇〇をプレゼント」とLINEのリンクを送る。インスタ→LINEの橋渡し
  • A社の事例での教訓：設定後、別のアカウントからコメントしてDMが本当に届くかを必ず試す（「他のアカウントからコメントしてもDMが来ない」ことが実際に起きた）
2-5. オープンチャット（オプチャ）
  • 何か：LINEのグループ機能。匿名で入れる
  • 何に使うか：販売開始前の"盛り上げ"（使い方の質問会・ビフォーアフター共有）。B社の事例では一番売れる場所。公式LINEの一斉配信より気軽に読まれる
  • 注意：12月GOでは必須ではない。立ち上げ後、ファンが増えてきたら追加でよい（案）
2-6. Instagram（配信の主役）
  • 何に使うか：リール（新しい人に届く）／ストーリーズ（フォロワーと距離を縮める・LINE誘導）／LIVE（実演・質疑で一気に売る）／ハイライト（使い方・お客様の声の常設）
  • BAN対策：投稿したリールを別の場所（Googleドライブ等）に保存しておく（B社の事例では過去のリールを全部保存している）
2-2. Lステップ（LINE公式に"つなぐ"拡張ツール）
  • 何か：LINE公式アカウントを高機能にする外付けの道具
  • 何に使うか（＝なぜ要るか）
機能何に使うか（美容物販の例）
ステップ配信登録した日から「1日目・2日目…」と自動で順番に配信。誰がいつ登録しても同じ教育を受けられる
タグ（お客様の印）「ブラシ購入」「アイロン検討中」「くせ毛」「ブリーチ毛」など。買った人に売り込みを送らない・悩み別に送り分ける
流入経路分析どのリール・どのストーリー・どの広告から何人入ったか分かる＝伸びる投稿が分かる
アンケート・回答フォーム髪質診断。答えでおすすめ商品を出し分ける
リッチメニューの切り替え未購入者には「おすすめ診断」、購入者には「使い方動画・お手入れ」のメニューに自動で変える
リマインド配信体験会・LIVE・セール締切の前日/当日に自動で送る
予約機能サロンでの体験・個別相談の予約
  • 注意：LINE公式1アカウントに"つなげる"配信ツールは1つだけ（Lステップとエルメ・UTAGEを同じアカウントに同時につなぐことはできない）。だから、A社の事例では入口のLINE＝Lステップ／講座のLINE＝UTAGEとアカウントを分けている
  • 似た道具：エルメ（無料プランから始められる・B社の事例で使用）。「最初はお金をかけずに始めたい」ならエルメ、「機能と分析をしっかり」ならLステップ
3. BAN（アカウント停止）の考え方と対策

前提：美容物販は「稼げる系」の商材に比べてLINEのBAN（停止）リスクは低め。ただしゼロではないので、止まっても売上が止まらない形にしておく。

対策何をするかなぜ
① 連絡先を2本持つLINE登録直後にメールアドレスも登録してもらう（UTAGEフォーム・登録特典と引き換え）LINEが止まってもメールで全員に連絡できる
② LINEアカウントを分ける入口・配信用（Lステップ）と、購入者・予備用を別アカウントにする1つ止まっても、もう1つは生きる（B社の事例は役割ごとに複数アカウント）
③ 友だちリストを定期的に書き出すLステップから毎月CSVで書き出して保存止まったときに「誰がお客様だったか」を失わない
④ 送りすぎない・煽りすぎない配信は週2〜3通が目安。ブロック率・通報が増えたら止める通報が多いと停止の原因になる
⑤ 規約違反の表現をしない「絶対」「髪が治る」等の言い切りを避ける（4章）法律違反は通報・停止の理由になる
⑥ インスタもバックアップリール・ストーリーの元データを保存／サブアカウントを用意インスタ停止で集客口が全部消えるのを防ぐ
⑦ 外部の自動化ツールをLINEに勝手につながない正規の連携ツール（Lステップ等）以外でLINEを操作しない正規でない自動化ツールをつないで止まった例が他社で出ている
4. 販売する前に必ず確かめる法律・表示（物販特有）
項目何を確かめるか何のためか
PSEマーク（電気用品安全法）ヘアアイロンは電気用品＝PSEマークが無いものは販売できない。仕入れ・OEMの場合、メーカー（輸入者）がPSEの手続きをしているか書面で確認違反すると販売停止・回収・罰則。最優先
特定商取引法の表記販売ページに「販売者・住所・電話・価格・送料・支払方法・発送時期・返品の条件」を載せる通販の義務。無いと決済サービスの審査も通らない
返品・交換の条件「初期不良は交換」「開封後の返品は不可」等を決めて表記書かないと、届いて8日以内は返品を受けることになる
薬機法・景品表示法「髪が修復する」「くせ毛が治る」「No.1」等の言い切りを使わない。効果は「個人の感想です」ブラシ・アイロンは医薬品・化粧品ではないので"効き目"は言えない
ステマ規制インフルエンサーに紹介してもらうときは「PR」「広告」を表示してもらう2023年10月から違反になった
お客様の声の掲載「掲載してよいか」「お名前の出し方」を書面（フォーム）で確認無断で載せると信頼を失い、トラブルにもなる
5. 参考事例：すでに運用している2つの事業から持ってくるもの
事例実際の動線このサロンに持ってくること
A社（講座ビジネス）インスタ（リールに決まった言葉をコメント）→ iステップでDM → 入口の公式LINE（Lステップ）→ 特典＋無料セミナー案内 → 受講生向けの公式LINE（UTAGE）→ 毎週の無料セミナーほぼこの形をそのまま使える。入口＝Lステップ、購入者側＝UTAGEの2アカウント構成／ステップ配信は10通以上・リマインドを強く／iステップは別アカウントから動作確認
B社（講座ビジネス）YouTube・インスタ → 公式LINE（エルメ・役割ごとに複数アカウント＝配信用・BAN対策用 等）→ オプチャで盛り上げ → セミナー → 個別相談 → 講座。LP・会員サイト・メールはUTAGEBAN対策（アカウント分散・リール保存・正規でないツールをLINEにつながない）／プリローンチ（販売前約25日・配信ネタ9本）の型／「どの数字を毎週見るか」の一覧

違うところ（そのまま写さない）：両社は「講座（情報）」を売る形。今回はモノ（ブラシ・アイロン）なので、①セミナー→個別相談より「使い方の実演（LIVE・動画）→ そのまま購入」が中心 ②在庫・発送・PSE・返品の準備が追加で要る ③買った後の「使い方フォロー」と「2本目・ギフト」でリピートを作れる。
