1. 利益の側と純資産の側

F2-10 では、株価を利益（EPS）と比べました。この章では、株価を純資産と比べます。F2-06 で見たとおり、純資産は返す約束のない資金で、会社が持っているものから返すべきものを引いた残りです。同じ株価でも、利益と比べるか、純資産と比べるかで、違う倍率が出ます。そして、その2つは1つの式でつながっています。

2. 純資産に対する株価の倍率

F2-06 から F2-10 と同じ架空の会社で計算します。純資産は400億円、発行済株式数は1億株、株価は1,500円です。数値はすべて説明のために作ったものです。

1株あたりの純資産は、400億円を1億株で割って400円です。株価を1株あたりの純資産で割った倍率を PBR と呼び、この会社では1,500÷400で3.75倍です。会社の純資産1円あたりに、市場が何円を払っているかを示します。

3. 純資産が生み出す利益率

純利益を純資産で割った率を ROE と呼びます。同じ会社では、100億円÷400億円で25%です。返す約束のない資金が、1年でどれだけの利益を生んだかを見る率です。

ROE も比なので、分子と分母に分けて読みます。利益が同じなら、純資産が小さいほど ROE は大きくなります。この分け方は、次の F2-12 で詳しく扱います。なお、取引所の用語集では、PBR と ROE の分母を「自己資本」と書いています。厳密には、純資産のうち株主に帰属する部分を使いますが、この章では架空の会社の純資産をそのまま使います。

4. 3つの指標をつなぐ式

PBR は、PER と ROE を掛けたものに等しくなります。架空の会社では、PER が15倍（F2-10）、ROE が25%なので、15×0.25で3.75となり、PBR と一致します。

一致する理由は、式を分けると分かります。PER は株価を EPS で割ったもので、EPS は純利益を株式数で割ったものでした。ROE は純利益を純資産で割ったものです。PER と ROE を掛けると純利益が打ち消し合い、株価を「純資産÷株式数」で割った形、つまり株価を1株あたりの純資産で割った PBR が残ります。

3つの指標は独立ではなく、どれか2つが決まれば、残り1つも決まります。

このため、PBR が大きいと聞いても、それだけでは何も分かりません。PER が大きいのか、ROE が大きいのか、その両方なのかを分けて読む必要があります。

5. PBR が1倍を下回るとき

PBR には、1倍という区切りがよく持ち出されます。PBR が1を下回るのは、市場が付けている値段が、帳簿上の純資産より小さいときです。1株あたりの純資産が400円のまま、株価が360円になったとすると、PBR は0.9倍です。

この状態には、少なくとも2つの読み方が並びます。1つは、市場が将来の利益を小さく見ているという読み方で、4節の式で言えば、PER か ROE のどちらかが小さくなっています。もう1つは、帳簿上の金額が実際の価値より大きいという読み方です。F2-06 で見たとおり、BS に書かれた資産の金額は、実際に売ったときの値段と同じとは限りません。PBR の分母そのものに、こうした性質があります。

どちらなのかを、このカリキュラムは判定しません。1倍という区切りは答えではなく、分子と分母のどちらを疑うかという、次の問いの入口です。

6. 片方だけを見ない理由

業種によっても、純資産の大きさには傾向の違いがあります。設備を多く持つ事業では、資産として記録される額が大きくなりやすく、設備をあまり持たない事業では小さくなりやすくなります。F2-10 の PER と同じく、同じ物差しで並べても前提が違い、業種ごとの傾向の分け方は L3 の F3-06 で扱います。

この章は、割安か割高かの判定はせず（F0-01 の線）、どの水準が適正かにも触れません。実在の企業の数値も使いません。PBR も ROE も、次に何を確かめるかを決めるための入口です。次の F2-12 では、ROE を3つの要素に分けます。
