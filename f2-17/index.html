1. 分散の効き目を数にする

F1-09 では、同じ方向に動かないものを組み合わせると全体の振れが小さくなる、という分散の直感を扱いました。この章では、その「同じ方向に動くかどうか」を数にします。

2つの量が一緒に動く度合いを、−1から＋1までの数で表した指標を相関係数と呼びます。＋1に近いほど同じ向きに、−1に近いほど逆の向きに動きます。A1-10 で定義だけ渡した語で、Fレーンだけを進む人のために、ここで1行にまとめました。この章では、この数が変わると全体の振れがどう変わるかを確かめます。

2. 相関の値と全体の振れ

架空の資産 A と B を、半分ずつ組み合わせます。どちらも、F2-16 で見た標準偏差が20%だとします。数値はすべて説明のために作ったものです。相関係数の値を変えて、組み合わせ全体の標準偏差を計算すると、次のようになります。

相関係数組み合わせ全体の標準偏差
＋1.0（完全に同じ向き）20%
0（一緒に動く傾向が見えない）約14.1%
−1.0（完全に逆の向き）0%

相関が0の場合だけ、計算の中身を示します。それぞれの持ち分の振れは0.5×20で10なので、その2乗の100を2つ足して200、平方根を取って約14.1です。相関が＋1のときは、単純に平均されて20%のままです。相関が−1のときは、互いに打ち消し合って0%になります。

同じ標準偏差20%の資産を2つ組み合わせても、相関の値によって、全体は20%にも約14.1%にも0%にもなります。F1-09 の直感を数にすると、こうなります。

3. 数の多さと散らし方

2節の表から分かるのは、相関が＋1に近いものどうしを組み合わせても、振れは小さくならないということです。相関が0に近ければ振れは小さくなり、−1に近ければさらに小さくなります。分散とは、数を増やすことではなく、同じ方向に動かないものを組み合わせることです。

S1-06 のバックアップでも、複製を増やすことと、失われ方を散らすことは別の対策でした。同じ弱点を共有しているものをいくつ並べても、まとめて駄目になります。セキュリティのレーンで見た形が、資産の話でも成り立ちます。

4. 相関の移り変わり

相関係数は、測った期間の中での関係を表した数で、期間が変われば値も変わります。

さらに、平常時には相関が低く見えた組み合わせでも、市場が大きく下がる局面では、相関が高まりやすいことが繰り返し観測されています。平常時の相関で計算した振れの小ささは、いちばん必要な場面で成り立たないことがあります。F2-14 で、流動性は必要なときに限って低くなることがあると見たのと同じ形で、平常時の数字は危機の場面を保証しません。

A1-10 で挙げた注意も、そのまま効きます。一緒に動くことと、原因であることは別です。数字は、いつのデータで測ったかで変わります。0に近いからといって、無関係とは限りません。

5. この章が渡さないもの

この章が渡すのは、示された相関の数字を読む見方と、相関が変わりうるという限界、数を増やすことと散らすことの違いです。配分の比率を計算する手順も、将来の相関の見積もりも、どの資産を組み合わせるかの判断も渡しません。

比率の計算手順を渡さない理由は2つあります。手順を渡せば、それは個別の投資判断になります（F0-01 の線）。また、4節のとおり入力の相関が動くので、手順は見た目ほど確かではありません。資産配分の考え方は L3 の F3-02 で扱いますが、そこでも比率は計算しません。

6. 相関を因果として見せる操作

この道具は、勧誘を見分ける場面でも効きます。「この指標とこの資産は連動している」という説明は、一緒に動いた期間があったという記述で、原因の主張ではありません。

A1-13 の問いも重なります。いつからいつまでを測った数字なのかを確かめます。測る期間を選べば相関の値は変えられるので、都合の良い期間を選んで示すことができます。この操作は、L3 の A3-01 で、都合のよい期間の選び方として正面から扱います。相関が高いことは、共通の原因があることの証拠になりません。
