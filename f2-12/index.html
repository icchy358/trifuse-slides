1. 効率の分解

F2-11 で、純資産がどれだけ利益を生んだかの率として ROE を計算しました。しかし、この1つの数字だけでは、何が効いてそうなったのかが分かりません。比は分子と分母に分けて読むというのが、F2-09 から続けてきた読み方です。この章では、分けるだけでなく、掛け算の形に組み替えます。

2. 総資産に対する利益率

純利益を総資産で割った率を ROA と呼びます。会社が持っているもの全体が、どれだけ利益を生んだかを示します。

F2-06 から F2-11 と同じ架空の会社で計算します。売上は1,000億円、純利益は100億円、総資産は1,000億円、純資産は400億円です。数値はすべて説明のために作ったものです。ROA は100億円÷1,000億円で10%、F2-11 の ROE は100億円÷400億円で25%でした。ROE は返す約束のない資金だけを分母にし、ROA は借りたものも含めた全体を分母にします。同じ利益でも、何と比べるかで率が変わります。

3. ROE の3つの要素

ROE は、利益率と回転率と財務レバレッジの3つの掛け算に書き換えられます。利益率は、売上のうちどれだけが純利益として残ったかです。回転率は、総資産に対して売上がどれだけあるかで、資産をどれだけ動かしたかを示します。財務レバレッジは、総資産が純資産の何倍かで、借りた分がどれだけ乗っているかを示します。

架空の会社では、利益率が100÷1,000で10%、回転率が1,000÷1,000で1.0回、財務レバレッジが1,000÷400で2.5倍です。掛け合わせると、0.10×1.0×2.5で0.25、つまり25%となり、F2-11 の ROE と一致します。

一致するのは、「純利益÷売上」「売上÷総資産」「総資産÷純資産」を掛けると、売上と総資産がそれぞれ打ち消し合い、純利益÷純資産だけが残るからです。F2-11 の、PBR が PER と ROE の掛け算になったのと同じ仕掛けです。ROA と ROE の関係も、この分け方の一部です。利益率と回転率を掛けたものが ROA の10%で、それに財務レバレッジの2.5倍を掛けたものが ROE の25%です。

4. 同じ ROE でも違う中身

架空の会社を3つ並べます。P社はここまでの会社と同じ形です。Q社は、利益率を小さく、回転率を大きくして、ROE を P社と同じ25%にしました。R社は、P社の利益率と回転率のまま、財務レバレッジだけを2倍にしました。

利益率回転率財務レバレッジROE
P社10%1.0回2.5倍25%
Q社2.5%4.0回2.5倍25%
R社10%1.0回5.0倍50%

P社は利幅が大きく、資産の回転はゆっくりです。Q社は利幅が小さいものの、資産を4倍の速さで回しています。ROE は同じでも、事業の形はまったく違います。

R社の行は、財務レバレッジを上げるだけでも ROE が大きくなることを示しています。借りる割合を増やすと、分母の純資産に対する利益の比は大きくなり、利益率も回転率も1つも改善していなくても、数字は良くなります。F2-09 で、自社株買いによって利益が同じでも EPS が増えるのを見たのと同じ形で、分母を小さくして良く見せる方法は、指標を問わずあります。

この表は、借りる額が増えても利息が増えないものとして単純化しています。実際には借入が増えれば利息も増え、その分だけ利益率は小さくなります。借りて ROE が上がるのは、借りたお金で得られる利益が、払う利息を上回るときだけです。そして、E1-02 で見たとおり、上に振れる仕組みはそのまま下にも振れます。借りた分は、業績が悪いときにも返す必要があります（F2-06）。

5. 3つに分けて見る手順

ROE が上がったと聞いたら、利益率が上がったのか、回転率が上がったのか、財務レバレッジが上がったのかを確かめます。1つ目は売り方や原価の側、2つ目は資産の使い方の側、3つ目は借りる割合の側の変化です。3つとも同じ方向に ROE を動かしますが、意味はまったく違います。

このカリキュラムは、どの形が良いかを判定せず、どの要素が効いたのかを分けて読めるようにします。

F2-08 で見たとおり、利益が出ていても、現金が入っているとは限りません。指標が良くなっていても、営業活動の現金が伴っていないなら、内訳を確かめる理由になります。A1-12 で数字を検算したのと同じ作業です。次の F2-13 では、稼いだ利益をどう分けるかを扱います。
