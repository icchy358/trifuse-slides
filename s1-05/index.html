1. 週末の点検

この回では、その考え方を端末のまわり全体に広げます。守るものが多いほど、守りきるのは難しくなるので、先に減らしてから、残ったものを硬くする順番です。

2. 画面ロックと使っていないアプリ

まずスマホです。田中さんのスマホは、画面を開くときに何も聞かれない設定になっていました。

S1-01 から S1-03 で扱ったのは、遠くから口座に入ろうとする相手でした。スマホそのものが手元を離れると、話が変わります。ロックのかかっていないスマホを拾った人は、メールも、パスワード管理ツールも、確認コードのアプリも、田中さん本人として開けます。S1-02 で集めた守りも、S1-01 の多要素認証も、開いたままの端末の中では働きません。

手元を離れる場面は、なくしたときや盗まれたときだけではありません。修理に出す、家族が触る、店に置き忘れる、といった場面もあります。田中さんは、画面ロックを設定し、短い時間で自動的にロックがかかるようにしました。

次に、アプリを3つに分けました。証券、銀行、決済、確認コード、メールのアプリは、口座への入口なので、更新を最優先にして多要素認証もかけます。ときどき使うアプリは、更新の対象として残しました。1年以上開いていないアプリは、消すことにしました。

田中さんのスマホからは、1年以上開いていないアプリが15個見つかりました（説明のための例）。消せば、そのアプリの更新も、次の4節で見る権限の見直しも、まとめて要らなくなります。

3. 家のWi-Fiの機器

次は、家の Wi-Fi の機器です。家の中のスマホやパソコンの通信は、すべてこの機器を通ります。端末をどれだけ硬くしても、ここが開いていれば、その手前で通信をのぞかれたり、設定を書き換えられたりします。

田中さんの機器は、8年前に買ったものでした（説明のための例）。こうした機器には、設定を変えるための管理画面があり、そこに入るパスワードが出荷時から決まっています。古い機種には、同じ機種で同じパスワードが使われているものもあります。S1-01 で見た使い回しが、買った時点で入っている状態です。

田中さんが確かめたのは、管理画面のパスワードを出荷時のものから変えたか、機器のソフトの更新が届いているか、作り手のサポートが終わった機種を使い続けていないか、の3点です（出典1）。S1-04 の更新の話は、スマホやパソコンだけでなく、この機器にも当てはまります。

4. 外のWi-Fi

田中さんは、週に何度か、駅前のカフェの無料 Wi-Fi を使っています。店や駅などが提供し、誰でもつなげる Wi-Fi を、公衆 Wi-Fi と呼びます。

公衆 Wi-Fi は「通信の中身が丸見えになる」と言われてきました。今は、多くのサイトやアプリの通信が暗号化されていて、途中で中身を読まれにくくなっています（どれくらい減ったかを示す数字は、ここでは扱いません）。

それでも、残っている危険があります。

残っている危険中身
どこにつないだかは見える中身が読めなくても、接続先は分かる
本物そっくりの偽の Wi-FiWi-Fi の名前は誰でも自由に付けられるので、名前は身元の証明にならない
つないだときの案内画面入力を求める画面が出ても、本物とは限らない（S1-03 と同じ形）

暗号化が守るのは、やり取りの中身です。相手が本物かどうかまでは守りません。鍵のマークの話と同じで、何が守られ何が守られないかは S2-04 で扱います。

田中さんは、公衆 Wi-Fi につないでいるときには、証券口座や銀行の画面を開かないと決めました。偽サイトに入る道は、回線の種類とは関係なく残ります。回線を疑うより、そこで開く画面を選ぶほうが確かです。

5. アプリに渡している権限

最後に、スマホのアプリの権限を見ました。アプリが、連絡先、位置、写真、マイクなど、端末の機能やデータに触れてよいかを、利用者が決める設定を、アプリ権限と呼びます。

田中さんのスマホでは、懐中電灯のアプリが、連絡先と位置情報への権限を持っていました（説明のための例）。画面には「許可しますか」と聞かれるだけですが、許可すると、アプリを出している事業者が、そのデータを使えるようになります。事業者がそのデータをさらにほかの会社へ渡すかどうかは、事業者がプライバシーポリシーに書いています。権限を与えるのは、自分のデータを、事業者の手に、さらにその先へ渡ることも含めて委ねる意思表示です。

田中さんは、3つの点で見直しました。その機能にその権限は要るか、要らないのに求めているなら何のためか、前に与えた権限を見直したことがあるか、です。地図のアプリに位置情報は要りますが、懐中電灯のアプリに連絡先は要りません。権限は設定画面から後で外せて、外して困ったら戻せます。

事業者が、集めたデータを何のために使い、誰に渡し、いつまで持つのかを書いた文書が、プライバシーポリシーです。全部読まなくても、何を集めるか、ほかの会社に渡すか、いつまで持つかの3か所を見れば、渡した先の見当がつきます。

自分のデータについて、事業者に何を持っているかを開示するよう求めたり、訂正や利用の停止を求めたりできる制度もあります（出典3）。どんな場合に求められるかには条件があるので、細かい手続きは制度の案内で確かめます。

6. 鍵の外側の入口

田中さんが土曜の午後に見つけたのは、ロックのないスマホ、出荷時のままかもしれない Wi-Fi の機器、外のカフェで開いていた証券口座の画面、使っていないアプリと、それが持っていた権限でした。

どれも、S0-EX で数えた入口の続きです。入口は、パスワードのかかったログイン画面だけではありません。開いたままの画面、初期設定のままの機器、与えたまま忘れた権限も、入口になります。

ただ、ここまでの手入れをすべて済ませても、スマホが壊れたり、なくなったりすることは防げません。次の S1-06 では、端末そのものを失ったときに、写真や書類や口座の手がかりを取り戻すための備えを扱います。
